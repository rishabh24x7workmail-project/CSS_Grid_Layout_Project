CSS Grid works with two types of tracks: • Explicit Grid: Tracks that you explicitly define using grid-template-columns and grid-template-rows. • Implicit Grid: Tracks created automatically by the browser when content exceeds the boundaries of your defined grid. Grid Mosaic Layout

A CSS Grid Mosaic Layout is a multi-column, multi-row design technique that mimics traditional tiled art, allowing asymmetric boxes to lock perfectly into a geometric layout. Unlike standard uniform grids, it uses spanning properties to create visual hierarchy

Neither is strictly "better" than the other; they are complementary tools designed for different jobs.

The Core Setup Requires Only a Defined Column Axis

The "mosaic" effect relies on individual grid items breaking the uniform structure by stretching across multiple tracks. • Items are sized using the shorthand properties grid-column and grid-row. For example, assigning grid-column: span 2; grid-row: span 2; to a specific block (often called a "featured" tile) creates a large focal point, while other items remain single-cell units

Spanning Properties Dictate Item Sizes

To build a classic mosaic, you only need to explicitly define the columns on the parent container using the display: grid; property. The rows do not need an explicit template because the browser’s layout engine calculates them automatically based on the content

Images Must Be Specifically Tamed

Because mosaic layouts frequently handle portfolio images, standard image rendering will break the grid lines. Achieving a true mosaic requires constraining the media elements to prevent overflow.

Mosaic vs. Masonry Layouts

While often confused, a strict mosaic layout is structurally different from a masonry (Pinterest-style) layout: Mosaic Layouts: Constrained to rigid, overlapping horizontal and vertical track lines. Elements must conform to a strict modular block matrix. Masonry Layouts: Items have a fixed width but variable vertical heights, causing items to shift upward into uneven columns. Historically achieved via JavaScript, browsers are evolving to handle this natively via newer features like grid-template-rows: masonry; or dedicated layout types.
